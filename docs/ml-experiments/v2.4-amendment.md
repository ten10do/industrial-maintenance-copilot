# Predictive Generalization V2.4 RUL 解释性计算修订

状态：`LOCKED AFTER R0/R1 COMPLETION AND BEFORE ANY R2/R3 RESULT`

## 原因

R0 与 R1 已证明，RUL family 的主要额外耗时来自每个 outer validation fold 对全部行、全部特征执行三次 permutation importance。R2/R3 包含约 177 个特征，这部分解释性计算远高于模型训练成本，不符合预注册的 bounded-resource 目标。R2 已打印第一个 outer fold 的开始信息，但在暂停时没有生成 R2 run JSON，也没有查看任何 R2/R3 指标。

## 修改

仅将 R2/R3 的 permutation importance 输入固定为每个 held-out Development fold 中确定性等距选取的最多 1,000 行，仍遍历全部特征、固定 `n_repeats=3`、固定 seed。R0/R1 已完成的全量 held-out importance 原样保留，不回算、不覆盖。

以下内容完全不变：

- inner/outer grouped CV、fold manifest 与 15 个 Development bearings；
- R0-R3 特征定义及所有模型候选；
- scaler、degradation baseline 的 train-fold-only 拟合；
- 原始/平滑预测及 MAE、RMSE、R²、late error、trajectory metrics；
- uncertainty、family 选择规则与全部 promotion thresholds；
- XJTU 结果仍只称为 Cross-Bearing Generalization Estimate。

Permutation importance 不参与调参、选模或 promotion，本修订因此不改变任何模型性能结论。最终报告必须标明 R0/R1 使用全部 held-out rows，R2/R3 使用上述确定性 bounded sample。
