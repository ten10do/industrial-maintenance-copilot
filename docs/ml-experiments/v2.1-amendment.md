# Predictive Generalization V2.1 资源修订

状态：`LOCKED BEFORE ANY V2 RUL RESULT WAS INSPECTED`

## 原因

预注册优先采用 XJTU-SY 15-fold Leave-One-Bearing-Out（LOBO）outer evaluation，并明确允许在运行成本过高时、查看指标前修订为固定 5-fold outer grouped CV。

在 Git SHA `d5c9dac0567db5aa3c786236ca6bcb85036b71ff` 上启动了 R0 的 LOBO 运行。每个 outer fold 需要对 23 个预注册候选执行 3-fold inner CV，即每个 feature family 需要 1,035 次 inner fit，四个 family 共 4,140 次 inner fit，另有 outer refit 和 permutation importance。实测首个 family 在数分钟内仍未完成，完整运行预计需要数小时。

运行在任何 feature family 完成前终止：

- 没有生成 `rul-r*-lobo.json`；
- 没有生成 summary/report；
- 没有读取或检查预测、MAE、RMSE、R²、late error、trajectory 或 per-bearing 指标；
- 没有据此修改 feature、candidate、hyperparameter、threshold 或 promotion policy。

## 修改

XJTU V2 outer evaluation 从 15-fold LOBO 改为预注册允许的确定性 5-fold grouped CV：

- group=`bearing_id`；
- 每个 outer validation fold 固定包含 3 个完整 bearing；
- 每个 operating condition 在每个 fold 恰好贡献 1 个 bearing；
- seed=`20260803`；
- 在任何重跑前生成并提交 `data/manifests/xjtu-v2-outer-folds.json`；
- 每个 bearing 仍恰好作为 outer validation 一次；
- outer train/validation 之间不得共享 bearing。

每个 outer train 内继续使用原预注册的 condition-balanced 3-fold grouped inner CV。以下内容完全不变：

- R0–R3 feature families；
- 23 个 candidate/hyperparameter 组合；
- train-fold-only scaler 和 degradation baseline；
- raw 与 causal EWMA 双报告；
- oscillation 定义；
- MAE `<= 5h`、R² `> 0`、late error `<= 3h`、oscillation rate `<= 0.10`；
- XJTU 结果仍仅称为 Cross-Bearing Generalization Estimate；
- 不存在新的 unbiased final test。
