# 安全说明

## 设备操作

- AI、规则服务和前端都不能直接调用设备命令。
- 高风险操作先写入待审批记录；主管/管理员填写意见后，批准接口才调用 Gateway。
- 重复批准返回原执行结果，不重复执行命令。
- 驳回、失败、执行结果、审批人和时间均持久化。
- Mock 结果不能解释为真实 PLC 或现场设备状态。

## 权限

- 管理员和主管：仿真控制、审批、验收、Agent 审计与调度。
- 维修工程师：查看资产/诊断，执行被分派工单；不能审批高风险操作。
- 服务端校验角色、被分派人和状态机，隐藏按钮不是唯一安全措施。

## 密钥与日志

- `.env`、数据库 URL、Redis URL、JWT Secret、LLM Key 和平台 Token 不进入 Git。
- 浏览器只使用相对 `/api`；服务端密钥不得使用 `NEXT_PUBLIC_*`。
- 日志只记录 Provider 名称、状态、耗时和脱敏错误，不打印请求头或连接串。
- CI 固定 `AI_ENABLED=false`，不访问付费模型或生产服务。

## 生产要求

生产发布前必须更换本地占位 Secret，使用 TLS 数据库/Redis，精确设置 CORS Origin，禁用自动 Seed，并配置真实 AI Provider 或明确关闭解释型 LLM 功能。生产不应把 Mock AI 输出标记为真实诊断。
